📸 How to Generate Your OG Image

Option 1: Screenshot (Recommended)

  1. Open your browser's developer tools (F12)
  2. Use "Device Toolbar" or "Responsive Design Mode"
  3. Set viewport to exactly 1200 x 630 pixels
  4. Take a screenshot of just the white box above
  5. Save as og-image.png in the public/ folder

Option 2: Browser Screenshot Tool

  1. Right-click the white box above
  2. Select "Inspect Element"
  3. Right-click the <div class="og-image"> in DevTools
  4. Select "Capture node screenshot" (Chrome/Edge) or "Screenshot Node" (Firefox)
  5. Save as og-image.png in the public/ folder
