This is the first post on this blog. This space will be used for technical writing, notes, and thoughts on software engineering, cryptography, and web technologies.

## Creating New Posts

To create a new blog post, simply add a new Markdown file to `src/content/blog/` with the following frontmatter:

```markdown
---
title: 'Your Post Title'
description: 'Brief description of the post'
date: 2025-11-08
---

Your content here...
```

## Features

This blog supports:

- **Markdown formatting** for easy writing
- Syntax highlighting for code blocks
- Automatic date sorting (newest first)
- Clean, readable newspaper-style design
- Fast static site generation with Astro
